# 머니 서바이벌 2 — 인생 대모험 🎮

다연쌤 금융교육 게임의 **생애주기 확장판**.
직업을 뽑고 → 월급을 굴리고 → **금리·빚·블랙스완**을 견디며 **28세부터 노후까지 파산 없이 살아남는** 시뮬레이션.

Vite + React, 실시간 교실 동기화는 **Firebase Realtime Database**.
**Firebase가 없어도 ‘혼자 연습’은 그대로 전부 동작합니다.** (그래서 배포만 해도 바로 데모 가능)

## 무엇이 10배가 됐나 (v1 → v2)

| 주제 | 새로 들어간 것 |
|---|---|
| 🎂 생애주기 | 28세 시작, 한 라운드=4년. 20대→30대→40대→50대→**은퇴(60+)**. 단계별 안내 카드 |
| 💰 나이별 소득곡선 | 20대 0.8배 → 40대 전성기 1.3배 → **60세 은퇴 시 근로소득 0**, 연금+이자·배당으로 생존 |
| 🧾 가계부(지출) | 매년 **생활비**(단계별 상승: 결혼·사교육 등) + 대출이자 + 보험료 자동 정산 |
| 📊 거시경제(금리) | 화면 상단 **기준금리** 표시. 금리↑ → 위험자산↓ & 대출이자↑. 속보/수동으로 변동 |
| 🏦 자산소득 | 적금 **이자**, 주식 **배당**이 매년 통장에 — 노후 생존의 핵심 |
| ⚠️ 레버리지·반대매매 | ‘빚내서 투자’(고급) 가능. 폭락 시 **마진콜(강제청산)** 자동 발동 |
| 🛡️ 보험·블랙스완 | 보험료를 내면 **큰 병·사고·사기**(블랙스완) 피해를 대부분 방어 |
| 💀 파산 | 순자산(자산−빚)이 마이너스면 **게임 오버** |
| 📈 UI | **Recharts 순자산 그래프**, 뉴스속보 배너, **아바타/스트레스 상태창**, 부동산 자산 추가 |

## Vercel 배포

> git 없이 **Vercel CLI**로 바로 올립니다. `money-survival2` 폴더 안에서 실행하세요.

```bash
npm i -g vercel
vercel login         # 브라우저로 로그인 (한 번만)
vercel --prod        # 이 폴더를 프로덕션으로 배포
```

- 처음 물어보는 것들: 프로젝트 이름/스코프는 **엔터로 기본값** 사용, 빌드 설정은 `vercel.json`에 이미 들어있어 자동 인식됩니다.
- 배포가 끝나면 `https://<프로젝트>.vercel.app` 주소가 출력됩니다.

### (선택) 교실 실시간 모드 켜기 — Firebase
‘수업 참여 / 다연쌤 화면’을 쓰려면 Vercel에 환경변수를 넣으세요.
Vercel 대시보드 → 프로젝트 → **Settings → Environment Variables** 에 아래 5개 추가 후 **재배포**:

```
VITE_FB_API_KEY        = ...
VITE_FB_AUTH_DOMAIN    = ...
VITE_FB_DATABASE_URL   = https://<프로젝트>-default-rtdb.firebaseio.com
VITE_FB_PROJECT_ID     = ...
VITE_FB_APP_ID         = ...
```

Realtime Database 보안 규칙(수업 중에만 열기):

```json
{ "rules": { ".read": "now < 1893456000000", ".write": "now < 1893456000000" } }
```

## 게임 흐름
- **혼자 연습**: 이름 → 직업 → (보험/대출) → 분산투자 → 속보 결과 → 다음 해… 노후까지. 파산하면 종료.
- **수업**: 학생은 ‘수업 참여’, 선생님은 ‘다연쌤 화면’. 다연쌤이 **속보/금리/다음 해**를 눌러 전원 동시에 진행.
- 끝에 **게임 종료** → 🏆 인생 최종 결산(시상대 + 효도왕).

## 구조
```
src/
  App.jsx      게임 전체(엔진 + UI). startRound / applyNews 가 핵심 로직
  storage.js   sGet/sSet/sList/sDel — Firebase 어댑터 (없으면 안전하게 no-op)
  firebase.js  Firebase 초기화 (env 없으면 초기화 생략)
  main.jsx     진입점
```
단위: **1칸 = 10만원**, **1라운드 = 4년**.
